## 三、供应与制造（Supply）

### 3.1 地理闭环

```text
深圳南山 —— 研发总部
广州黄埔 —— 自建工厂（光学器件组装 + 整机 + R1 戒指）
香港门店 —— 大中华少量零售窗口（大陆未正式上架）
海外官网 / 眼镜店 —— 主销售与处方交付
```

约 **90% 供应链伙伴在 90 分钟车程内**（CEO 公开表述），典型大湾区硬件打法。

### 3.2 上游关键点（公开可核验 + 行业推断）

| 模块 | 公开/报道信息 | 含义 |
| --- | --- | --- |
| 光波导 | 报道指**广纳四维**为衍射波导核心供应商；其扩产与黄埔产业政策绑定 | 供应瓶颈可直接影响交付周期 |
| 光学总成 | 自研 **Even HAO / HAO 2.0**（投影机 + 波导 + 镜片协同） | 壁垒在系统集成，非单一外购模组 |
| Micro-LED 光机 | G2 宣称投影机体积较上代小约 40%；行业层面依赖少数 Micro-LED 供应商 | 与 NIMO 同类供应链风险 |
| 处方镜片材料 | 官网标明 **Mitsui Chemicals MR™ Series** | 高端树脂片路线，利于薄镜叙事 |
| 镜片加工 | **自有/指定实验室数字化车削**，处方与波导层粘合一体；**不支持第三方随意换片** | SKU 与交期由品牌中心仓控制 |
| 结构 | 镁合金框 + 钛镜腿；无螺丝铰链专利叙事 | 对标高端眼镜工艺 |
| 组装 | 广州自建厂「光学器件组装 + 整机组装」；产能爬坡期「每天数百台」量级（报道） | 规模仍小，靠高客单养利润 |

### 3.3 供应侧特征（操盘视角）

1. **预购 / 定制交付**：处方订单天然有滞后，利于去库存，但拉长「下单→戴上」体验。  
2. **自建厂保工艺**：把光学Know-how 留在体内，扩张依赖黄埔产能与波导供应商扩产。  
3. **大陆不做 C 端铺货**：避免卷入国内价格战，供应链服务海外优先。

| 台渠道 | 3C/精品/电信（iNNOHOME） | — | 宝岛视光 | 台哥大+眼镜伙伴 |

| 融资估值 | ~$1B | 早期 | 更高估值段 | 上市公司业务线 |

**战略含义：**

1. **Even 已证明 NIMO 路线在全球可成立**——且抢先完成独角兽叙事与台湾正规上市。  
2. **台湾柜面：** Even 与 Rokid 价格同带（约 2 万），但渠道不同；NIMO 若走宝岛，可打「视光专业验配 + 更轻 + 含镜更亲民」，与 Even 的 3C/精品路径错开。  
3. **风险：** 媒体与消费者会把 NIMO 直接叫成「Even 平替/中国版 Quiet Tech」——需在光学叙事、重量、价格、验配时效上建立可感知差异。  
4. **供应启示：** Even 押自建厂+波导核心供方；NIMO 需同样守住光机/波导良率与处方交期，否则在「定制眼镜」承诺上输给 Even 的实验室模式或宝岛的门店模式。

## 九、结论（给操盘用）

1. **供应：** 深研广产、自建组装、波导绑定本地核心供方；处方镜片中心制，SKU 复杂度高但库存压力可控。  
2. **销售：** 欧美 DTC + 高端眼镜店为主；台湾已由 iNNOHOME 走 3C/精品/电信，**不是宝岛独占模型**。  
3. **SKU：** G2 双框型 × 三色 × 平光/单光多档 + R1 + 夹片；软件靠 Conversate/Hub 拉长生命周期。  
4. **市场：** 小体积高客单、已融资独角兽、细分标杆；与 NIMO 定位撞车最狠——NIMO 必须以**更轻、更可验配、更亲民正规价、更深视光 KA**建立区隔，而不是复述 Quiet Tech 口号。
