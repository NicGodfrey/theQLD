## 〇、决策摘要（先看这页）

台湾 AI 眼镜已不是「教育品类」阶段，而是**分割市场**：

| 已被占位 | 谁占了 |
| --- | --- |
| 繁中日常摄像 AI | HTC VIVE Eagle（台哥大 + 眼镜伙伴） |
| 视光连锁「有屏有摄像」 | Rokid × 宝岛（约 NT$19,999） |
| 无摄像 Quiet Tech（3C/精品/电信） | Even G2 × iNNOHOME（NT$19,990） |
| 全球时尚心智（无正规） | Ray-Ban Meta 水货 |

**NIMO 不能再只靠「无摄像头」口号。**  
可用空位是：**视光主场上的无摄像 HUD 日常镜**——更轻、门店验配、含镜总价更清晰/更亲民。

| 方案 | 一句话 | 推荐度 |
| --- | --- | --- |
| **A. 视光主场（宝岛/同等 KA）** | 用验配闭环打 Even，用无摄像打 Rokid | ★★★★★ 主推 |
| **B. 双轨协同** | 眼镜成交 + 精选 3C/内容种草 | ★★★★☆ 资源够时升级版 |
| **C. 电信/3C 对撞** | 学 Eagle/Even 铺密度与专案价 | ★★☆ 不建议作主路径 |
| **D. 精品慢火** | 少量高端眼镜店 + 高溢价 | ★★★ 作补充或试水温 |

**默认建议：以 A 为主案上市，3–6 个月后视数据升 B；C 仅作局部曝光，不扛 KPI。**

**合规前提（详见「认证与上市节奏」）：** BSMI / 电池 / NCC 未到手前不上柜；规划按 **BSMI ≈3 个月、NCC 等 ≈1 个月**（可并行），样品送指定实验室。  
**价格节奏（现行）：** 开局默认 **平光 $499 / 单光主销 $599（含镜）**——**高规同价绝杀** Even/Rokid 两万心智；视光渠道叠 **半价戒指** 导购。是否回抬视上市后数据另议，不自动涨价。

## 一、市场洞察

### 1.1 品类阶段

- 全球智能眼镜高速放量；台湾已有 **正规货 + 水货 + 影音 AR** 多层供给。
- 消费者决策从「有没有」转向「**正不正规、配不配度数、敢不敢天天戴、会不会被拍**」。
- 高度近视社会 + 眼镜连锁专业度，使**验配成为本地刚需**，不是可选项。

### 1.2 台湾三条赛道（勿混战）

| 赛道 | 买点 | NIMO 是否进入 |
| --- | --- | --- |
| A. 日常摄像 AI（听/拍） | 繁中助理、旅行拍摄 | 不正面硬刚 Eagle |
| B. 轻显示 HUD | 字幕、提词、导航 | **主战场** |
| C. 影音巨幕 | 追剧/掌机 | 不进入 |

### 1.3 价格带心智（2026）

| 带 | 代表 | 消费者解读 |
| --- | --- | --- |
| ~1.5–1.6 万 | Eagle 主销 | 「正规入门 AI 镜」 |
| ~2.0 万 | Rokid / Even G2 | 「有显示的旗舰带」 |
| 水货 0.9–1.8 万 | Meta / 小米代购 | 「便宜但不保」 |
| 影音 0.8–3.5 万 | RayNeo / XREAL 等 | 另一品类 |

**NIMO 定价必须回答：** 相对 Even/Rokid，我是「同价更好戴」还是「更低总拥有成本（含镜）」？

### 1.4 渠道结构含义

| 通路类型 | 代表 | 适合卖什么 |
| --- | --- | --- |
| 视光连锁 | 宝岛 | 处方、信任、复购 |
| 电信门市 | 台哥大 | 体验密度、绑约降门槛 |
| 综合 3C | 全国电子、灿坤 | 看见、试用、礼品 |
| 精品 3C/生活 | 法雅客、诚品 | 调性、种草 |
| 电商 | momo、PChome | 比价、预约到店 |

Even 已占「3C+精品+电信」；宝岛已被 Rokid 教育「眼镜店能卖 AI 镜」。  
→ **后发者最优切口仍是视光深度，而不是再铺一套全国电子。**

## 二、消费者洞察

### 2.1 谁会买（优先人群）

| 人群 | 动机 | 顾虑 | NIMO 钩子 |
| --- | --- | --- | --- |
| **办公/会议族（28–45）** | 提词、通知过滤、少掏手机 | 摄像头隐私、漏音尴尬 | 无摄像 + 静默 HUD |
| **高度近视换镜族** | 反正要配一副新眼镜 | 智能镜重、丑、配不准 | 29g、验配、当本命镜 |
| **跨境/双语使用者** | 翻译字幕 | 只「念出来」不够 | 看得见的翻译（相对 Eagle） |
| **科技尝鲜但反感水货** | 想跟全球潮流 | Meta 无保固 | 正规通路 + 本地售后 |
| **企业/专业采购（次优先）** | 合规可戴进会议室 | 品牌知名度 | Camera-free 合规叙事 |

### 2.2 决策旅程（台湾特有）

```text
内容种草（YouTube / Mobile01 / IG）
  → 恐惧点核对（隐私？度数？保固？）
    → 想试戴（电信/3C 或眼镜店）
      → 关键成交点：验光是否专业、能否当日/短期取镜
        → 私域复购 / 转介绍
```

论坛已反复出现的槽点（可当作设计输入）：

- 电信店体验差（锁链试戴、尺寸不全）→ **眼镜店专业体验是差异**  
- 有摄像不敢进会议室 → **无摄像是刚需，不是情怀**  
- Even/处方实验室交期长 → **门店验配时效可打**  
- 总价不透明（框+片+戒指）→ **含镜套餐清晰可打**

### 2.3 一句话 Jobs-to-be-done

> 「我想换一副能天天戴的近视镜，顺便让必要信息出现在眼前——但不要拍别人，也不要看起来像戴了台电子设备。」

## 三、竞争洞察（简表）

| 对手 | 他强在哪 | 他弱在哪 | NIMO 怎么打 |
| --- | --- | --- | --- |
| **Even G2** | Quiet Tech 心智、全球高端叙事、台已上市、价带清晰 | 3C 为主、处方中心制、总价易上冲、重量叙事弱于 29g | **视光主场 + 更轻 + 含镜套餐** |
| **Rokid@宝岛** | 验配网络、字幕场景、宝岛背书 | 有摄像、更重、价高 | **同店讲「隐私日常版」**，分流而非硬抢 |
| **HTC Eagle** | 繁中、门市密度、本土情感、资安 | 无显示屏 | 不拼语音，拼「看得见」 |
| **Meta 水货** | 外型心智 | 无保、AI 区隔、难验配 | 正规化对照 |
| **影音三强** | 巨幕体验 | 非日常镜 | 不进赛道 |

**竞争结论：**  
主竞品是 **Even（同哲学）** 与 **Rokid（同柜）**；Eagle 是心智对照组；Meta 是舆论对照组。

## 四、NIMO 优劣势（SWOT）

### 优势（S）

1. 产品哲学与验证过的全球空位同向：无摄像 + HUD + 日常镜。  
2. **重量叙事强（约 29g）**，相对 Eagle/Rokid/Even 有感知差异。  
3. 大陆已跑通「含配镜」价值锚（约 ¥2,499 起），可迁移为台湾「套餐透明」。  
4. 适合眼镜店旅程（验光→选框→配片），与股东/眼镜产业基因一致（若持续强化）。  

### 劣势（W）

1. 台湾零品牌资产；Eagle/Rokid/Even 已占舆论与柜面。  
2. 繁中 App、本地售后、NCC/BSMI 等合规需补齐才能正规卖。  
3. 无 Meta/HTC 级营销预算与电信门市密度。  
4. 「无摄像头」差异化被 Even 部分稀释。  

### 机会（O）

1. 宝岛已被 Rokid 教育，可谈**第二品牌分品类**（隐私日常镜）。  
2. 论坛对隐私、全天戴、体验店质量有真实不满。  
3. Even 未深度绑定视光连锁 → 时间窗仍在。  
4. 企业/校园会议场景需要 camera-free。  

### 威胁（T）

1. Even 快速用电信专案起量，心智固化为「无摄像 = Even」。  
2. 宝岛若给 Rokid 更强排他，柜面进不去。  
3. 水货价格 ethique 拉低预期。  
4. 光学/处方良率与交期一旦翻车，连锁信任难修复。

## 五、四套 GTM 方案详述

---

# 方案 A｜视光主场打法（推荐主案）

### A1. 战略一句话

> **把 NIMO 做成「能在验光台上成交的本命智能近视镜」——用宝岛（或同等 KA）打穿 Even 的 3C 优势，用无摄像打穿 Rokid 的隐私短板。**

### A2. 产品

| 项 | 动作 |
| --- | --- |
| 主 SKU | NIMO 标准款（含基础单光套餐）+ Demo 机 |
| 增值 | 防蓝光 / 变色 / 偏光升级片 |
| 本地化 | 繁中 App、台湾常用 App 通知白名单、会议/捷运/旅行场景预设 |
| 服务包 | 「验配 + 14 天舒适调整 + 硬件保修」捆绑，序列号绑门店 |
| 不做 | 首发不推企业复杂套装、不推影音巨幕配件 |

**产品话术铁律：**  
「不是多买一台 3C，是升级你每天那副眼镜。」

### A3. 价格

| 项 | 建议方向 |
| --- | --- |
| 零售锚点 | **含基础配镜套餐 NT$12,990–15,990**（低于 Even/Rokid 裸机心智，或与 Eagle 同带但「有屏」） |
| 升级片 | 门店加价清晰公示 |
| 对比页 | 做「总拥有成本」：NIMO 含镜 vs Even 框+片+戒指 |
| 纪律 | MAP；电商只做预约核销，不长期破价 |
| 上市礼 | 延长保修 / 功能片折扣，避免直接打到水货带 |

> 具体价位需按成本、关税、门店毛利重算；原则是 **「有屏隐私镜，总价不高于 Rokid/Even 常用成交带」**。

### A4. 渠道

| 阶段 | 动作 |
| --- | --- |
| 0–3 月 | 宝岛（优先）或同等连锁 **20–40 标杆店**；认证验光师 ≥2/店 |
| 3–9 月 | 加密至 80–120；策略联盟店分级导入 |
| 并行 | 官网/LINE 预约到店；不做全国电子主铺货 |
| 明确不做主 KPI | 电信绑约冲量（避免体验翻车与毛利塌陷） |

**门店旅程 SOP（25–35 分钟）：** 问诊隐私场景 → 验光瞳距 → 抬头唤醒三场景试戴 → 含镜方案 → 会员建档。

### A5. 营销

| 层级 | 内容 |
| --- | --- |
| 大创意 | 「思绪归位，心流自成」本地化：「会议室也敢戴的智能近视镜」 |
| 必打 3 条片 | 会议无摄像 / 全天无压痕 / 验光师讲解为何 AI 镜要验配 |
| 媒体 | 科技媒体闭门体验 + 眼镜产业媒体；避免只进 3C 横评和巨幕对比 |
| 论坛 | Mobile01/ePrice 真实长测（配镜完成、压痕、续航） |
| KOL | 验光师、职场创作者、双语旅居；少找纯数码跑分网红 |
| 联合 | 与宝岛会员积分、校园/企业巡展 |

### A6. 90 天里程碑

- 标杆店就绪率、认证通过率 ≥ 90%  
- 试戴→成交、配镜完成率达标  
- NPS / 重大售后 7 日关闭率  
- 是否进入 KA 下一季主推清单  

### A7. 适用条件

- 能谈进宝岛或同等视光 KA  
- 处方交期与售后 SLA 可承诺  
- 接受前 2 季「密度优先于铺货广度」

# 方案 B｜双轨协同打法（资源升级版）

### B1. 战略一句话

> **眼镜店负责赚钱与口碑，3C/内容负责让人知道「台湾还有比 Even 更适合配镜的无摄像镜」。**

### B2. 产品

- 与 A 相同主 SKU  
- 增加 **Plano/时尚无度数款** 供 3C 展示与礼品  
- 所有 3C 包装印「处方请至合作眼镜门市」二维码  

### B3. 价格

- 眼镜店：含镜套餐（主）  
- 3C/电商：硬件价略高于套餐感知，迫使「去店里配更划算」  
- 严禁 3C 长期低于眼镜店含镜总价  

### B4. 渠道

| 主 | 辅（控量） |
| --- | --- |
| 宝岛等视光 KA | 精选法雅客/诚品 1 柜体验（抬调性） |
| LINE/官网预约 | momo「预约验配」页，不主打直接完售处方 |

**明确：不与 iNNOHOME 式全国电子+台哥大全面对撞。**

### B5. 营销

- A 的全部内容资产  
- 加一条对照结构（不点名攻击）：「买显示眼镜，记得算上配镜与等待」  
- 与 Even 上市话术错峰：对方讲 Quiet Tech 品牌，我方讲 **验配完成的 Quiet Life**  

### B6. 何时启用

- A 试点转化健康后  
- 有独立繁中增长团队与备机池

# 方案 C｜电信 / 3C 对撞打法（不建议作主路径）

### C1. 战略一句话

> 学 Eagle/Even：用门市密度 + 专案价快速起量。

### C2. 产品 / 价格 / 渠道 / 营销（概要）

| 维度 | 做法 | 风险 |
| --- | --- | --- |
| 产品 | 以无度数/低服务 SKU 为主 | 丢掉「本命近视镜」定位 |
| 价格 | 绑约专案把门槛打到数千元 | 毛利与品牌溢价双杀 |
| 渠道 | 电信 + 全国电子级铺货 | 体验质量不可控（Eagle 已有负面帖） |
| 营销 | 大曝光、促销售 | 与 Even 同柜同质，沦为参数/价格战 |

### C3. 结论

仅可作 **局部城市曝光或员工购**，**不能作为 NIMO 台湾品牌定义战役**。若主走 C，几乎必然变成「Even 平替」。

# 方案 D｜精品慢火打法（试水温 / 补充）

### D1. 战略一句话

> 选 8–15 家精品眼镜店（含部分 2020EYEhaus 级独立店），高体验、控货、高口碑，再决定是否进 KA。

### D2. 要点

| 维度 | 做法 |
| --- | --- |
| 产品 | 全规格处方能力展示；框色限量 |
| 价格 | 可略高于 A 套餐，强调手工验配 |
| 渠道 | 精品店深度培训；不做电商破价 |
| 营销 | 小而美长测、设计师/建筑师人群 |

### D3. 适用

- KA 谈判卡关时的过渡  
- 或 A 之外的高端补充线

## 七、认证前提与上市节奏框架（先框架，再定开局价）

> 智能眼镜在台湾零售，实质门槛是：**能合法上柜（BSMI + 电池相关 + NCC）+ 有本地申请人/进口商 + KA 验配就绪**。  
> 下列周期来自客户经验表（同行样品量级）与公开认证实务对照——**作排期假设，签约实验室后锁定**。

### 7.0 客户建议审视（准不准）

| 客户说法 | 判断 | 说明 |
| --- | --- | --- |
| **BSMI ≈ 3 个月** | **基本准确（偏稳妥）** | 含锂电安全/EMC 的整机，端到端常 **8–12+ 周**；若电芯随机抽测、整改、验厂/体系文件不齐，拖到 3 个月很常见。纯「报告齐后行政审查」可短至数周，**排期应按 3 个月留缓冲**。 |
| **其他（NCC 等）≈ 1 个月** | **大致准确（偏乐观）** | BLE/Wi‑Fi 类低功率设备，资料齐、一次过测约 **3–6 周**；「1 个月」可作目标，须预留整改重测。可与 BSMI **并行**，总关键路径仍常被 BSMI/电池卡住。 |
| **找实验室做 NIMO 认证** | **方向对** | 须走 **BSMI/NCC 认可实验室**；需台湾当地申请人（进口商/代理）。客户表页签为同行参考（如 INMO 样品清单），**NIMO 以实验室报价单终确样品数**。 |
| 样品量级（客户表） | **可作备样参考** | 见下表；电池「随机」电芯数量因方案而异，**89 颗电芯**量级说明电池是长周期项，须尽早备料。 |

**客户表示例样品需求（备样清单，非最终法定数量）：**

| 认证项目 | 样品需求（客户经验） |
| --- | --- |
| BSMI | 4 个整机 + 4 个电池包 |
| 电池随机 | 约 89 个电芯 |
| NCC | 1 个整机 + 1 个传导定频 + 1 个辐射定频 |

**额外必做（常被忽略）：** 繁中标示/说明书合规、本地进口商资格、序列号与保固体系、KA 门市上样合格——认证到手 ≠ 自动能卖好。

### 7.1 合规节奏（倒排上市）

```
T0  冻结硬件/天线/电池方案 → 备样
T0–T+4w   NCC 送测（目标约 1 个月，可并行）
T0–T+12w  BSMI + 电池路径（规划 3 个月）
T+10w     认证进度闸门：未达 80% 则顺延开卖日
T+12w     证书到手 → 才允许公开零售与 KA 出货
T+12w+    软开业 / 正式开卖（价格模式见下）
```

| 阶段 | 动作 | 产出 |
| --- | --- | --- |
| 认证期 | 实验室合同、送样、整改、本地申请人递件 | BSMI / NCC 证书；电池报告 |
| 预热期（可与认证末段重叠） | KA MOU、TOT、体验桌、闭门媒体（不公开放价销售） | 店清单、神秘客脚本 |
| 开局价决策（建议开卖前 2–4 周） | 复盘 Even/Rokid/Eagle 价带与档期 | 选择 **新品优惠** 或 **正常价** |
| 开卖 | 视光 KA 主场出货 | 配镜完成率北星启动 |

### 7.2 开局价盘：高规同价绝杀（默认执行）

**原则：** 不打「更便宜」，打「**和 Even/Rokid 同一标价带，规格全面更高**」。

| 对位 | 竞品 | NIMO 开局 | 绝杀点 |
| --- | --- | --- | --- |
| 两万心智 | Even / Rokid ≈ NT$19,990–19,999 | **单光 1.60 含镜 $599**（≈NT$19,168） | **同价带已含处方片**；无摄像、更轻 |
| Even 真买单 | 裸机+片 ≈ 2.5–3.1 万（+戒更高） | **$599 ± 半价戒** | 总拥有成本全面更低 |
| 入门尝鲜 | Eagle ~1.5–1.6 万 | **平光 $499**（≈NT$15,968） | 有屏入场，仍低于 2 万锚 |

| 开局默认（对客） | KA 提货（销售收入） |
| --- | --- |
| 平光 **$499** | **$324.35**（×65%） |
| 单光 1.60 **$599** | **$359.40**（×60%） |
| 其余单光/渐进 | 开局表见 KA 文档（均为「原标价−$100」） |

**视光半价戒（导购）：** 戒指 MAP **$249** → 购镜加购 **$124.50**；仅认证视光店、绑主机订单。用于交互心智 + 组合价格力（对齐 Even 半价 R1 玩法，战场在验光台）。

**回抬：** **非自动。** 上市后视转化、合规、竞品促销再决定是否 +$100 回后备价盘；可只回抬部分 SKU 或延长优惠锚。详细见《NIMO台湾KA政策与定价方案.md》。
