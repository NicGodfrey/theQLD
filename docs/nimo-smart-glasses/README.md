**核心结论速览**

1. 智能眼镜已进入主流渗透窗口；「科技品牌 × 眼镜产业」是验证过的胜出路径。  
2. NIMO 应以眼镜渠道为主成交与服务闭环，3C/内容负责种草引流。  
3. 台湾优先落地，宝岛眼镜作为第一 KA，走「无摄像头日常镜」差异化柜面。  
4. 台湾格局：HTC Eagle 占繁中日常心智，Rokid×宝岛占视光显示柜，**Even G2 已占 Quiet Tech 无摄像 HUD**，Meta 有心智无正规。  
5. NIMO 对 Even：同哲学竞品；需靠更轻、含镜价、视光 KA 验配深度区隔，而非复述无摄像头口号。  
6. **台湾 GTM 主推方案 A（视光主场）→ 验证后升 B（双轨）；慎用电信/3C 对撞。**
