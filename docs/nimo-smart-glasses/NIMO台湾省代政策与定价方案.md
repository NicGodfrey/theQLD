## 一、决策摘要（先看这页）

1. **价盘逻辑继承大陆：** 统一零售价 → 省代提货约 **63%** → 二级约 **70%** → 样机 **5 折买断**；省代毛利目标 **约 36–38%**，门店端再留空间。  
2. **台湾零售锚在「含镜总价」：** 主销单光 1.60（0–600）建议 **NT$13,990**，落在 Eagle 带上方、Even/Rokid 裸机 **~2 万** 之下，打「总拥有成本」而非裸机参数价。  
3. **SKU 按光学能力切七档：** 平光 + 单光三档（1.60 / 1.67 / 1.74）+ 渐进三档（同折射率），升级路径清晰，门店可现场升客单。  
4. **渠道纪律：** 视光主场（宝岛/二链）优先；禁止电信/3C 专案价定义品牌；MAP + 窜货重罚。  
5. **省代一年北星：** 认证门店 **100 家**、商品机提货 **3,000 台**、配镜完成率与价格合规双达标——不是铺柜数。

## 二、洞察如何约束定价（给老板的「为什么」）

| 台湾事实 | 对定价/政策的约束 |
| --- | --- |
| Even G2 官方 **NT$19,990**（处方/戒指另计），占 Quiet Tech | 主销含镜套餐必须 **明显低于「Even 框+片」总拥有成本」**，否则无转化理由 |
| Rokid×宝岛约 **NT$19,999**，视光有屏已教育 | 可同店分流「隐私日常版」；价带可靠近但靠无摄像+更轻+含镜透明 |
| Eagle ~1.5–1.6 万，无显示 | 平光/主销单光可与其同带竞争「正规入门」，多卖「看得见」 |
| 水货 Meta 0.9–1.8 万拉低预期 | **禁止**上市礼/专案打进水货带；用延保、片升级折扣保价盘 |
| GTM 主案 A：视光主场，密度优先 | 省代考核看 **验配门店与配镜完成**，不看全国电子铺货 |

**定位句（对外统一）：**  
NIMO——无摄像头、轻到忘记的智能近视镜；在眼镜门市完成专业验配。

> 二级代理价是省代批给区域代理/重点连锁的建议上限纪律价；省代对直营认证店可在不破二级价、不破 MAP 前提下自行设定出货，但须报备总部价盘表。

### 4.2 报价纪律（照搬并本地化）

- 对消费者执行 **统一建议零售价（MAP）**；官网/LINE/momo 预约核销 **不得低于 MAP**。  
- 渠道价（省代/二级）**不可对消费者与公域泄露**；泄密严查。  
- 门店综合毛利目标（含增值膜层）：**35%–50%**（活动期以书面报备为准）。  
- 经销商对门店话术：强调验配、保修、含镜透明；禁止「水货同款更便宜」类表述。  
- **最终以正式合作协议为准。**

### 4.3 膜层 / 增值加价（建议门店加价带，不计入上表提货）

## 五、台湾省代政策包（对齐大陆手册八大块）

### 5.1 授权与区域

| 项 | 政策 |
| --- | --- |
| 授权 | **台湾省独家省级经销商**（含澎湖等离岛是否纳入书面约定） |
| 下级 | 可发展二级代理、直营 KA（宝岛等）、认证单体店 |
| 禁区 | 未经报备不得发展大陆水货倒流、跨境直播低价 |
| 首月 | **考核期**；连续两月未达门槛可降为非独家或终止洽谈 |

### 5.2 价保与返利

| 项 | 标准（建议） |
| --- | --- |
| 月返 | 有效提货额 **1%** |
| 季返 | **2%** |
| 年返 | **2%** |
| 超任务 | 超全年提货任务部分额外 **1%** |
| 价保 | 官方调价/大促提前通知；已提未售合规库存按书面补差或返利抵扣 |
| 不纳入 | 跨区低价、私自让利、未备案活动、窜货库存 |

### 5.3 样机政策

| 项 | 标准 |
| --- | --- |
| 上样价 | **NT$6,490 / 台** 买断（统一平光样机） |
| 门店门槛 | 单店商品机提货 **≥10 台**，样机 **1 台** + 专区陈列 |
| 省代赠样 | 每新开 **10 个认证店赠 1 台样机**，不设上限，定期核验 |
| 用途 | 仅演示展示；赠样核销、到店上样留痕 |

### 5.4 物料 / 展台

| 项 | 标准 |
| --- | --- |
| 触发 | 新品期采购商品机 **每满 100 台** 可申请 |
| 支持 | 对应 **10 套** 展台与物料（省代分配，优先样板店） |
| 限制 | 真实铺货满 **10 店** 后方可申下一批 |

### 5.5 门头 / 陈列补贴（台湾版）

| 项 | 标准 |
| --- | --- |
| 触发 | 已提样机 + 商品机提货 ≥5 台 + 真实出样可试戴 |
| 补贴 | **NT$2,000 / 店 / 月**（对标大陆 ¥200 量级上修；按当地核销） |
| 兑现 | 连续上样 ≥1 季度；按规范上墙并月传陈列/试戴记录 |
| 取消 | 撤样、造假、遮挡或换成竞品主推位 → 停补并可追回 |

### 5.6 样板店店长支持

| 项 | 标准 |
| --- | --- |
| 触发 | 首家样板店月销 **≥15 台**（台湾客单高于大陆，台数略降） |
| 支持 | 总部承担店长基础薪资补助（上限参照当地基本工资政策）+ 培训 |
| 验收 | 一季内跑通接待–验光–配镜；凭证可核验 |
| 节奏 | 1 周上样 → 2 周体验 → 4 周转化；达标再复制 |

### 5.7 售后兜底

| 项 | 标准 |
| --- | --- |
| 整机保修 | **12 个月**（购货或激活起算） |
| 调换货 | 购后 **6 个月内**，限平光、包装配件外观完整，可调畅销规格 |
| 上市首季 | 质量问题优先 **只换不修**（非人为） |
| 流程 | 门店收件 → 省代汇总 → 总部/授权检测核销 |
| 不适用 | 进水、私拆、改装、配件缺失、外观老化等 |

### 5.8 红线

窜货、乱价、假激活、未备案破价、泄露渠道价、电信专案价对外定义品牌——**一经查实：停货、取消返利、取消独家、追究违约。**

## 七、财务敏感测算（供内部，不外传）

### 7.1 单台经济学（以主销单光 1.60 为例）

| 角色 | 价格 NT$ | 空间 |
| --- | ---: | --- |
| 消费者 | 13,990 | — |
| 省代进货 | 8,850 | 毛利 5,140（36.7%） |
| 二级进货 | 9,800 | 相对零售 30% |
| 样机 | 6,490 | 降低试水成本 |

若年提货 3,000 台、结构按「1.60 占 55%、升级占 30%、渐进 10%、平光 5%」粗算：

- 混合零售均价 ≈ **NT$15,400**  
- 混合省代进货均价 ≈ **NT$9,750**  
- 省代进货总额 ≈ **NT$2.93 亿**  
- 省代账面毛利总额（未扣返利/运营）≈ **NT$1.70 亿**  
- 返利合计约 1%+2%+2% ≈ **5%** 量级（按规则计提）→ 需从毛利中预留  

> 以上为 **价盘推演**，未计入关税、运保、售后准备金、市场费；签约前须财务重算底价。

### 7.2 与「打 Even」的财务结论

- 主销 **13,990 含镜** 对比 Even **19,990 裸机**，门店好讲。  
- 渐进 1.67 **19,990** 可承接「愿为舒适加价」客群，而不必把品牌锚在电信数千元专案。  
- 禁止为冲量把主销打到 **&lt;12,000**：会同时撞水货带与毁掉省代/门店利润。
