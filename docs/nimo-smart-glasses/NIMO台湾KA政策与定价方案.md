| 项 | 内容 |

| 角色 | **台湾 KA**（如宝岛眼镜等连锁；**不称省代**） |

## 一、决策摘要

1. **平光标准零售价锚定 USD $599**（约 NT$19,168 / ¥4,313），含镜套餐对客标价。  
2. **首销优惠 −$100**：首销期对客 **$499**（约 NT$15,968 / ¥3,593）；**总部按台补差 $100**，保证 KA 仍按标准零售价享受约定毛利，不被促销吃掉。  
3. **KA 毛利预留（按标准零售价）：** 平光 **35%** · 单光 **40%** · 渐进 **42%**；另加提货额 **3% 返利**。  
4. **我方销售收入** = KA 进货价（包运税）= 零售 × (1 − 毛利率)；返利与首销补差从市场/返利科目核销。  
5. 渠道只设 **KA / 认证门店**，不再设「省代」层级话术。

## 二、为什么这样定（洞察 + 宝岛现实）

| 约束 | 动作 |
| --- | --- |
| Even 裸机 ~NT$19,990；Rokid@宝岛 ~NT$19,999 | 平光标价 $599（~1.92 万）进同一心智带；**首销 $499** 制造「第一波必买」 |
| 宝岛前期难做平凹自制 | SKU 全部 **NIMO 镜片交付**；交期与良率由品牌 SLA；KA 不背实验室 |
| 要让连锁更有钱赚 | 单光/渐进毛利 **40%/42%** 高于大陆省代结构；+3% 返利；首销补差保毛利 |
| 包运税 | 报价与合同价均为 **DDP/包运税到 KA** 口径，避免到岸扯皮 |

**首销规则（建议写入协议）：**

- 对客宣传价 = 标准零售 − $100；价签双标：「首销价 / 标准价」。  
- **补差 $100/台** 由总部在核销周期补给 KA（或抵货款），**不从 KA 毛利里扣**。  
- 首销期结束后恢复标准 MAP；未售库存按书面价保规则处理。  
- 禁止 KA 在首销价上再叠私自让利（避免双杀价盘）。

## 四、KA 进货价 = 我方销售收入（包运税）

### 4.1 毛利与返利定义

| 品类 | KA 毛利率（按**标准零售价**） | 返利 | KA 进货价公式 |
| --- | ---: | ---: | --- |
| 平光 | **35%** | 提货额 **3%** | 零售 × **65%** |
| 单光（三档） | **40%** | 提货额 **3%** | 零售 × **60%** |
| 渐进（三档） | **42%** | 提货额 **3%** | 零售 × **58%** |

- **销售收入（开票给 KA）** = 上表进货价（包运税）。  
- **返利后净收（测算）** = 进货价 × (1 − 3%)；首销补差 $100 另列市场费用。  
- 首销期 KA **账面绝对毛利**仍 = 标准零售 × 毛利率（因有 $100 补差）。

## 五、KA 政策包（宝岛可谈）

### 5.1 合作定位

- 身份：**台湾 KA（连锁关键客户）**，非省代经销商话术。  
- 光学：前期 **100% NIMO 镜片**（平光/单光/渐进及约定膜层）；门店负责验光、瞳距、接待成交。  
- 目标门店：先 **20–40 标杆店** → 视配镜完成率加密（与 GTM 主案 A 一致）。

### 5.2 返利与价保

| 项 | 标准 |
| --- | --- |
| 返利 | 有效提货额 **3%**（可拆月/季兑付，合计 3%） |
| 首销补差 | **$100/台**，核销需序列号 + 小票/系统出库 |
| 价保 | 官方调价/结束首销提前书面通知；合规库存补差 |
| 红线 | 窜货、叠加私自破价、泄露 KA 进货价 → 停货/取消返利 |

### 5.3 样机与培训

| 项 | 标准 |
| --- | --- |
| 样机 | **$299/台** 买断（平光展示）；专区陈列 |
| 门槛 | 店均商品机提货达标后上样（建议 ≥5–10 台/店，签约锁定） |
| 培训 | 总部 TOT：问诊–验光–试戴–含镜成交；神秘客稽核 |

### 5.4 售后

- 整机保修 12 个月；上市初期质量问题优先整机换新（非人为）。  
- 镜片为 NIMO 体系：处方重做/不良按光学 SLA，不甩给 KA 实验室。

## 七、会上可直接念的五句

1. 平光**零售锚定 $599**（约 ¥4,313 / NT$1.92 万）；**首销再减 $100 卖 $499**，制造开局脉冲。  
2. 我们**包运税**卖给宝岛等 KA，平光**销售收入 $389.35/台**；单光/渐进按 60%/58% 倒算。  
3. KA 预留毛利：**平光 35%、单光 40%、渐进 42%**，另 **3% 返利**；首销 **$100 总部补差**，毛利不被促销挖空。  
4. 前期镜片**全走 NIMO**，连锁不背平凹生产，利润用价盘让足。  
5. 组织上只称 **KA**，不称省代；任务看门店验配与价盘合规。
