## 一、决策摘要

1. **标准零售锚：平光 USD $599**（≈NT$19,168 / ¥4,313）。  
2. **新品优惠：对客 $499**；渠道共担——KA 提货按 **$499 × 65% = $324.35**，**不再另做总部 $100 补差**。  
3. **回抬：优惠期结束 → 零售回 $599，提货回抬至 $599 × 65% = $389.35**。  
4. 毛利率口径不变：平光 **35%**（即提货 65 折）· 单光 **40%**（60 折）· 渐进 **42%**（58 折）+ 提货额 **3% 返利**。  
5. **开局走优惠还是正常价**：认证完成后、开卖前 2–4 周，按竞争烈度二选一（见 GTM）。

## 四、回抬与价保

| 项 | 规则 |
| --- | --- |
| 优惠窗口 | 开卖起 **60–90 天** 或约定首批台数（协议锁定） |
| 回抬 | 对客恢复标准 MAP；新提货按正常轨；已按优惠轨提货的未售库存 **书面价保补差**（补至渠道不亏回抬） |
| 禁止 | 优惠价上再叠私自让利；未报备的长期破价 |
| 返利 | 仍按 **实际提货额 3%**（优惠期基数更低，返利绝对额同步下降） |

## 五、KA 政策要点（摘要）

- 身份：**KA**；前期镜片 **NIMO 供应**。  
- 门店：先 20–40 标杆 → 加密；认证验光师 ≥2/店。  
- 上市前提：BSMI + 电池 + NCC（见 GTM；BSMI 规划约 3 个月）。  
- 售后：12 个月整机；上市初期质量问题优先整机换新（非人为）。

## 六、会上五句

1. 平光**标准零售 $599**；要脉冲就开 **新品优惠 $499**。  
2. 优惠期渠道共担：提货 **$499×65%≈$324**；回抬后 **$599×65%≈$389**。  
3. 单光/渐进同理：先减 $100 再按 60%/58% 倒算。  
4. **认证未齐不上柜**；BSMI 按 3 个月排期。  
5. 开卖前再看竞争，在「优惠轨 / 正常轨」里二选一，框架先锁死。
