台湾智能眼镜已不是「教育品类」阶段。HTC Eagle 占繁中日常摄像心智，Rokid×宝岛 占视光有屏柜面，Even×iNNOHOME 占无摄像 Quiet Tech（3C/电信），Meta 有全球审美却无正规通路。NIMO 与 Even 产品哲学高度同构——若只喊「无摄像头」，上市即变平替。

B 是放大器，C 是陷阱，D 是保底；A 为骨、B 为翼

资源不够时只做 A+D。B 必须等 A 的配镜完成率与 NPS 健康后再开；C 绝不能作品牌定义战役。

B 双轨（升级）
  • 眼镜店赚钱口碑；精品 3C/内容破圈
  • Plano 展示款 + 预约验配码
  • 3C 价不得挖空含镜套餐
  • 辅线仅法雅客/诚品级 + momo 预约
  • 不对撞全国电子 + 台哥大全面铺货
C 电信/3C（陷阱）
  • 学 Eagle/Even：密度 + 专案价
  • 产品偏无度数、营销偏促销
