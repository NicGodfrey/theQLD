# NIMO × 宝岛眼镜 KA 合作计划（商务精简版）

> 供谈判与内部立项快速对齐｜完整版见《NIMO智能眼镜全球操盘计划与宝岛眼镜KA合作计划.md》

---

## 1. 为什么合作

| NIMO 带来什么 | 宝岛得到什么 |
|---------------|--------------|
| 隐私优先日常 AI 眼镜（无摄像头/无扬声器/29g） | 差异化智能品类，避开纯参数战 |
| 可验配（近视至800/远视至200/散光） | 发挥验光与镜片加工主场优势 |
| 镜片升级包利润设计给渠道 | 高于纯卖电子的综合毛利结构 |
| 培训、演示、售后与联合营销支持 | 会员智能升级故事与话题流量 |

**一句话：** 宝岛卖的不是又一台 3C，而是「会员下一副日常眼镜的智能升级」。

---

## 2. 对市场局势的共同判断

- 全球 AI 眼镜高速增长，但台湾成交卡在 **试戴 + 验配 + 售后**。  
- 灿坤已联合小林、蔡司打「3C+配镜」；宝岛需要 **光学主场的智能答案**。  
- Rokid 等显示型产品已进光学渠道 → NIMO 以 **久戴、隐私、含验配价格带** 区隔，而非同质硬刚。

---

## 3. 合作模式（建议）

| 条款 | 建议 |
|------|------|
| 关系层级 | 战略 KA（非纯分销） |
| 区域 | 台湾 |
| 独家 | 「无摄像头 HUD 日常 AI 眼镜」光学连锁 **12–18 个月阶段独家**（保留品牌官网少量直销例外） |
| 上柜节奏 | S 旗舰 8–12 → A 标准 60–100 → B 引流 80–150 |
| 利润结构 | 主机中毛利 + **镜片/加工高毛利归门店** |
| 返利 | 提货 × 验配完成率 双指标阶梯返利 |
| MDF | 销售额 3–5% 联合营销 |
| 售后 | 门店快判；主机 48h 换修通道 |

---

## 4. 首年目标锚（可谈）

- 上柜：150–200 店（含引流店）  
- 销量：8,000–12,000 副  
- 验配完成率：≥90%  
- 宝岛占 NIMO 台市场销售：≥60%
