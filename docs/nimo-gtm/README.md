## 核心结论（一页纸）

1. **主战场是眼镜渠道**（验配闭环）；3C 负责种草与线索导流。  
2. **定位**：隐私优先、29g 全天可戴的日常近视 AI HUD 眼镜（无摄像头）。  
3. **全球节奏**：中国样板 → 台湾/华人桥头堡 → 亚太 → 欧美合规。  
4. **台湾 KA**：以宝岛为主经销/主 KA；与既有 Rokid 品类共存（全能 AI vs 隐私日常镜）。  
5. **首波**：约 40 家认证门店，小而美验证转化后再扩至 80–100 家。
