## 0. 执行摘要

NIMO（深圳比特幻境 BitFantasy）定位为「日常全天候可佩戴的近视智能眼镜」：无摄像头、无扬声器，29g 级轻量化，0.03cc 微型光机 + Micro LED + 体全息波导，功能聚焦导航、翻译、提词、消息过滤等「静默 HUD」。首发定价约 **¥2,499 起（含近视镜）**，产品哲学是「先是眼镜，再是智能」。

全球智能眼镜正处于 **2026 拐点年**：出货量从千万级向数千万级跃迁，品类从「极客数码」快速切向「处方眼镜 + AI」。标杆路径是 Meta × EssilorLuxottica：技术方负责 AI/软件，眼镜巨头负责设计制造、验配与全球零售网络。NIMO 的差异化窗口在于：

| 维度 | 主流音频/摄像 AI 眼镜 | NIMO |
|---|---|---|
| 品类心智 | 3C 穿戴 / 相机眼镜 | 日常近视镜 + 静默信息提示 |
| 隐私立场 | 摄像头争议高 | 无摄像头，会议/校园/职场友好 |
| 渠道主战场 | 3C / 品牌直营 / 电商 | **眼镜连锁验配为主，3C 为辅** |
| 价格带 | 多数 ¥3,000–¥20,000+ | **大众处方价带（约 ¥2,499）** |
| 转化逻辑 | 试玩功能 | **验光—选框—配镜—智能升级** |

**全球操盘一句话战略**：  
以「处方智能镜」锚定眼镜渠道基本盘，用 3C 渠道做认知与尝鲜，用亚太（中国大陆 + 台湾 + 日韩新）做第一阶段规模化，欧美以合规隐私与专业人群切入，三年内完成「品类教育 → 渠道深耕 → 区域复制」。

**台湾宝岛合作一句话战略**：  
不做「又一个上架的 AI 眼镜」，而是做宝岛体系内的 **「智能处方标杆 SKU」**：用验配壁垒、门店 SOP、会员运营与差异化定位（隐私/轻量/价格），在 Rokid 等竞品已占位的前提下抢占「日常可戴」细分心智。

## 1. 全球市场洞察

### 1.1 市场规模与阶段判断

综合多家机构口径（定义差异较大，宜作区间理解）：

- **AR 眼镜**：约 2025 年 **$1.8B**，2033 年有望达 **$35B** 量级（高增速情景，CAGR 可超 40%）。
- **AI 智能眼镜广义市场**：约 2025 年 **$2.9B**，向 2030 年代中期数倍扩张。
- **出货量视角（更贴近操盘）**：2025 年全球智能眼镜出货约 **850 万副**量级，2026 年有望加速至 **2,000 万副+**；其中 **音频智能镜贡献量，HUD/显示类贡献价值**。

**阶段结论**：  
品类已过「有没有」的概念验证期，进入「谁能成为每天戴的第二副/第一副眼镜」的规模化争夺期。胜负手不再只是芯片算力，而是 **外观自然度 × 佩戴舒适 × 处方验配 × 渠道信任 × 价格可达**。

### 1.2 区域机会地图

| 区域 | 市场特征 | NIMO 机会 | 优先级 |
|---|---|---|---|
| **中国大陆** | 百镜大战、供应链近、眼镜连锁分散但活跃 | 股东/门店资源可快速铺货；用「含度数 2499」打价格心智 | P0 |
| **台湾** | 近视率极高、眼镜连锁集中、验光专业度高、宝岛已导入 AI 眼镜 | 处方刚需强；可做「眼镜渠道精耕样板市场」 | P0 |
| **日韩** | 审美严苛、轻量化偏好、隐私敏感、连锁/百货强 | 无摄像头 + 轻量外形契合；需本地设计联名 | P1 |
| **东南亚** | 年轻人口、电商强、验配能力不均 | 电商+授权商双轨；先新加坡/马来做形象 | P1 |
| **北美** | Meta 品牌壁垒高、光学零售高度组织化 | 切隐私敏感职场/教育；走独立光学连锁与 DTC | P2 |
| **欧洲** | GDPR/隐私监管严、光学渠道专业 | **无摄像头是合规叙事优势**；先德法英光学连锁试点 | P1–P2 |
| **中东** | 高端消费、时尚太阳镜文化 | 联名款/高端镜框；非主量仓 | P3 |

### 1.3 品类分化：NIMO 该站哪条赛道

当前全球路线大致四条：

1. **音频/摄像 AI 镜**（Ray-Ban Meta、Rokid 等）——量最大，渠道可 3C+眼镜双栖。  
2. **显示 HUD / 信息提示镜**（Even Realities G1、NIMO）——强调日常、专注、低打扰。  
3. **真 AR / 空间计算镜**——仍偏早期与企业。  
4. **运动/垂直场景镜**——细分刚需。

NIMO 明确落在 **路线 2**：用「砍掉」换来可全天佩戴与渠道可卖性。全球叙事应统一为：

> **Everyday Prescription AI Glasses** —— 不是下一台手机，而是你本来就要换的那副眼镜。

### 1.4 关键成功要素（对标 Meta × EssilorLuxottica）

1. **品牌时尚背书**（Ray-Ban）→ NIMO 需用设计联名/本地设计师补足。  
2. **全球光学零售与验配网络** → NIMO 必须以眼镜 KA 为骨架。  
3. **处方能力把智能镜推进「配镜篮」** → 含度数包价是正确打法。  
4. **供应链规模与成本下降** → 中国供应链是 NIMO 成本优势源。  
5. **培训与售后体系** → 门店不会卖「会坏的眼镜」除非服务闭环。

## 2. 双渠道上中下游市场分析

智能眼镜同时跨 **3C 数码价值链** 与 **眼镜光学价值链**。NIMO 的操盘本质是：**上游借 3C/光学供应链效率，中游做「眼镜形态的智能硬件」定义权，下游以眼镜渠道完成信任成交，3C 渠道完成认知放量。**

### 2.1 产业链总览

```text
上游（器件/材料）          中游（整机/品牌/软件）         下游（渠道/服务/用户）
─────────────────        ─────────────────────        ──────────────────────
Micro LED / 光机         整机设计与 ID                 眼镜连锁（验光配镜）
波导 / 光学模组          OS / App / AI 引擎            独立眼镜店 / 医院视光
电池 / 钛合金结构件      处方工程与镜片适配            3C 连锁 / 品牌专卖
主控 / 传感器 / BT       品质与认证（FCC/CE/NCC）      电商 / DTC / 运营商
镜片基材与镀膜           品牌与内容生态                企业/教育团购
OEM/ODM 代工             售后与固件 OTA                二手/配件/延保
```

### 2.2 3C 数码渠道：上中下游

#### 上游（3C 视角）
- **关键环节**：主控 SoC、连接模组、传感器、微型电池、光机/显示驱动、声学（NIMO 弱化）、结构件。  
- **中国优势**：微型光机、钢壳电池、精密结构、整机组装成本与迭代速度。  
- **风险**：高端 Micro LED、特定光学专利、海外认证周期。  
- **对 NIMO 含义**：成本结构可支撑大众价；但需锁定光机/波导良率与长期供应协议，避免「能发布不能铺货」。

#### 中游（3C 视角）
- **玩家**：消费电子品牌、AI 创业公司、ODM。  
- **竞争逻辑**：参数、生态（手机互联）、内容、营销声量。  
- **NIMO 中游角色**：不做全能 AI 终端，做「手机通知/导航/翻译的视觉外设 + 本地过滤引擎」。  
- **关键能力**：App 体验、固件稳定性、手机生态兼容（iOS/Android）、OTA、隐私合规声明。

#### 下游（3C 视角）
| 渠道形态 | 作用 | NIMO 用法 |
|---|---|---|
| 电商（官方/平台旗舰） | 认知、比价、全国覆盖 | 官方商城 + 天猫/京东等形象店；台湾 momo/PChome 后期 |
| 3C 连锁（Best Buy、电讯商、顺电等） | 试玩、科技人群种草 | **辅助渠道**：城市旗舰点体验，不做处方主成交 |
| 品牌快闪 / 科技展 | 媒体与 KOL | 发布与节点战役 |
| 运营商/企业 IT | 团购 | 北美子市场试点 |

**3C 渠道的本质短板**：不会验光、不会瞳距/成像调校、退换货成本高、难讲「这是一副眼镜」。  
因此 3C 适合 **「体验与获客」**，不适合作为 NIMO 的 **「成交与复购主引擎」**。

### 2.3 眼镜渠道：上中下游

#### 上游（眼镜视角）
- 镜框材料（β-钛、板材）、铰链工艺、镜片（树脂/功能片）、镀膜、OEM 镜架产能。  
- 全球格局：EssilorLuxottica 等巨头纵向整合强；中国镜架产能集中、性价比高。  
- **NIMO 要点**：智能模组必须「藏进」传统镜架工艺语言；镜片定制（近视 ≤800、远视 ≤200、散光、防蓝光/变色/偏光）是渠道可卖的前提。

#### 中游（眼镜视角）
- 品牌商、批发商、镜片加工中心、区域经销商。  
- 价值分配：传统眼镜利润大量来自 **镜片与验配服务**，而非镜框本身。  
- **NIMO 中游机会**：把「智能主机」做成高客单镜框，同时把镜片加工、功能片升级做成门店毛利池（镜片加价、镀膜、会员套餐）。

#### 下游（眼镜视角）
| 渠道形态 | 全球/区域特征 | 对 NIMO 的价值 |
|---|---|---|
| 大型连锁（宝岛、博士、JINS、LensCrafters…） | 标准 SOP、会员池、采购集中 | **KA 主战场** |
| 独立眼镜店 | 信任强、分散 | 区域代理覆盖 |
| 医院/视光中心 | 专业背书 | 教育/高度数场景 |
| 眼镜电商 | 增长但验配弱 | 引流到店 |

**眼镜渠道线下仍占绝对主导**（中国眼镜消费线下占比可超 90% 量级）。智能眼镜越「像眼镜」，越必须走这条路。

### 2.4 双渠道冲突与协同矩阵

| 议题 | 3C 渠道诉求 | 眼镜渠道诉求 | NIMO 裁决 |
|---|---|---|---|
| 定价 | 促销、比价 | 维护专业客单与镜片毛利 | **全球统一主机价；镜片由门店定价** |
| 库存 | 快进快出 | 体验机 + 慢周转处方 | 3C 浅库存；眼镜店深度陈列 |
| 人员能力 | 会讲参数 | 会验光调校 | 双轨培训包 |
| 售后 | 换新为主 | 调校/维修/再验配 | **眼镜店为服务中枢** |
| 营销 | 科技炫酷 | 护眼、舒适、时尚 | 「日常眼镜升级」统一话术 |
| 独家 | 要首发 | 要区域/品类独家 | 台湾眼镜渠道可给宝岛阶段性独家 |

### 2.5 价值链利润池（操盘定价参考）

建议把一笔成交拆成四层利润池，便于和 KA 谈判：

1. **智能主机**（品牌毛利主仓）  
2. **处方镜片与功能片**（门店毛利主仓）  
3. **验配/调校服务费**（门店）  
4. **配件/延保/会员增值**（共建）

对标行业经验：处方化后，光学零售端总客单与粘性显著高于纯硬件零售。NIMO 应用「主机不乱打折、镜片可组合促销」保护品牌与门店双边利益。

## 3. NIMO 全球操盘计划

### 3.1 战略定位与目标用户

**品牌定位**  
> NIMO —— 专注力的日常眼镜。隐私优先，轻到忘记，智能只在需要时出现。

**核心人群（全球统一，区域微调）**
1. **处方刚需白领 / 研究生**：通勤导航、会议提词、跨语言场景。  
2. **隐私敏感专业人士**：金融、法律、教育、医疗行政（无摄像头是门槛票）。  
3. **既有换镜周期用户**（18–24 个月换一副）：把智能做成「这次换镜的升级选项」。  
4. **轻度科技早期采用者**：愿意为新形态付费，但拒绝「头戴设备感」。

**非优先人群（阶段性）**：重度短视频创作者、强 AR 游戏用户、需要摄像记录的 Vlog 人群——交给竞品。

### 3.2 产品与价格带策略

| SKU 层级 | 建议构成 | 价格带（示意） | 渠道 |
|---|---|---|---|
| **入门处方包** | 主机 + 基础近视片 | 当地等价 ¥2,499 / NT$ 约 1.1–1.3 万 | 眼镜主渠道 |
| **功能片升级包** | +防蓝光/变色/偏光 | +镜片差价 | 眼镜门店 |
| **设计联名款** | 本地设计师/时尚联名框型 | 溢价 15–40% | 旗舰店/快闪 |
| **企业版** | 批量 + MDM/隐私声明包 | 团购折扣 | 直销 |
| **体验无度数版** | 演示/太阳镜片 | 用于 3C 与展陈 | 非主销 |

**产品路线图（操盘向）**
- **H2 2026**：稳定 Gen1（续航、App、处方工艺、门店 SOP）。  
- **2027**：多框型（亚洲脸宽适配）、双色显示或亮度升级、配件生态（充电仓/运动镜腿）。  
- **2028**：区域定制（欧洲合规固件、北美企业功能）、轻度健康提示（非医疗宣称）。

### 3.3 全球 Go-to-Market 节奏（18–36 个月）

#### Phase A｜品类立住（0–6 个月）
**战场**：中国大陆核心城市 + 台湾样板  
**动作**：
- 官网/公众号 DTC 承接；核心眼镜连锁标杆店落地。  
- 建立「验光—试戴 HUD—处方加工—交付调校」标准工时与良率。  
- KOL 聚焦「全天佩戴真实生活」而非参数评测。  
- 完成关键认证清单（目标市场 NCC/BSMI、CE、FCC 等按进入顺序）。

**阶段 KPI**：标杆城市月销、试戴转化率 ≥ 15%、7 日激活率、退货率、门店 NPS。

#### Phase B｜双渠协同放量（6–18 个月）
**战场**：大陆下沉连锁 + 台湾全岛 + 日韩/新马试点  
**动作**：
- 眼镜 KA 复制宝岛/博士类合作模型。  
- 3C 只开「体验岛」：不与眼镜店抢处方单。  
- 推出联名框与企业团购包。  
- 建立区域总代 + 直营 KA 混合架构。

**阶段 KPI**：活跃销售门店数、店均月销、处方占比、复购配件率、区域盈亏平衡。

#### Phase C｜全球网络化（18–36 个月）
**战场**：西欧光学连锁、北美独立光学集团、中东精品  
**动作**：
- 以「Privacy-first HUD glasses」叙事进入监管敏感市场。  
- 与区域镜片品牌（依视路/蔡司体系门店）做验配认证合作。  
- 评估是否引入战略光学股东/产能合作，复制 Meta-EL 结构的「轻量版」。

### 3.4 渠道架构：全球「眼镜 70 / 3C 20 / 其他 10」

**目标销售结构（成熟期）**
- 眼镜连锁及专业视光：**70%**
- 3C / 电商形象与尝鲜：**20%**
- 企业/教育/跨境 DTC：**10%**

**层级管理**
1. **全球 Key Account**：跨国或区域龙头连锁（如宝岛体系、潜在东南亚集团）。  
2. **区域授权分销**：覆盖独立店。  
3. **品牌直营 DTC**：价格锚与会员数据中枢。  
4. **3C 体验合作方**：按城市点位签约，不签全国包销处方权。

### 3.5 市场营销操盘

**全球统一信息架构（Message House）**
1. **Brand**：思绪归位，心流自成。  
2. **Product**：29g / 无摄像头 / 全天可戴 / 处方友好。  
3. **Proof**：光机 0.03cc、分散配重、仅佩戴者可见、典型续航场景。  
4. **CTA**：去眼镜店验光试戴，而不是「线上下单碰运气」。

**战役节奏**
- 常青内容：真实佩戴 Vlog、会议/通勤场景。  
- 节点：开学季、春节/圣诞换镜季、企业年中采购。  
- 禁忌：过度承诺「AR 世界」、偷拍暗示、医疗疗效宣称。

### 3.6 组织与能力建设

建议全球操盘最小编制：
- 全球渠道负责人 1 + 区域 GM（大中华 / APAC / EU）  
- 验配技术培训团队（飞轮：培训官 → 门店教练）  
- KA 商务与零售运营  
- 市场与内容（中英繁本地化）  
- 客户成功（固件、App、退换政策）

**门店赋能包（全球标准）**
1. 15 分钟试戴脚本  
2. 处方加工规范与 QC 清单  
3. 竞品对比卡（对音频摄像镜、对真 AR）  
4. 售后 4S：调校 / 换片 / 固件 / 延保  

### 3.7 财务与资源投放原则（方向性）

- **市场费用**：向「试戴转化」倾斜，而非纯曝光；门店联合广告占区域费用 40%+。  
- **渠道费用**：台阶返利 + 体验机支持 + 培训认证奖金，避免无条件高扣点。  
- **库存**：主机按周补；镜片半成品区域仓；滞销框型 90 天评估。  
- **成功标准（36 个月）**：眼镜渠道贡献 ≥ 65% 销量；台湾样板店均月销进入连锁智能品类前二心智；全球活跃门店 ≥ 目标阈值（由管理层按产能核定）。

### 3.8 风险清单与对冲

| 风险 | 影响 | 对冲 |
|---|---|---|
| Meta/大厂降维 | 份额与舆论 | 死守隐私/轻量/处方价带差异 |
| 门店不会卖 | 库存积压 | 认证店制度、驻店督导、演示激励 |
| 处方良率/成像投诉 | 口碑崩 | 瞳距/屈光严格适配表、拒配标准 |
| 渠道价格战 | 品牌损伤 | 主机 MAP 政策、窜货处罚 |
| 认证延误 | 出海延期 | 认证并行、市场排队进入 |
| 宝岛已与 Rokid 绑定 | 台湾进场难 | 差异定位 + 非冲突品类叙事 + 集团多品牌门店分层 |

## 4. 台湾市场专项判断

### 4.1 为什么台湾是 P0 样板

1. **近视刚需密度高**，处方眼镜是高频刚需消费，不是纯科技尝鲜。  
2. **连锁集中度相对清晰**：宝岛集团门店规模领先（集团约 **470 家**量级；直营宝岛约 **226**，策略联盟约 **123**，另有文雄、镜匠、SOLOMAX、米兰等），便于 KA 操盘。  
3. **验光专业与仪器投入成熟**，正好匹配波导/HUD 对瞳距与屈光的敏感。  
4. **宝岛已验证 AI 眼镜可卖**：与 Rokid（乐奇）合作，体验网点已从约 51 家扩至约 **101 家**，售价带约 NT$19,999（活动价）。说明门店、会员、媒体链路已被教育，**品类教育成本低于纯空白市场**。  
5. **华语内容与大陆供应链协同成本低**，适合作为「全球眼镜渠道 SOP 输出地」。

### 4.2 竞争格局（台湾）

| 玩家 | 渠道姿势 | 与 NIMO 关系 |
|---|---|---|
| Rokid × 宝岛 | 眼镜渠道独家叙事强，功能更「全能 AI」 | **直接货架竞争**，但产品哲学不同 |
| Ray-Ban Meta 等 | 品牌强，偏时尚/音频摄像 | 心智竞争；隐私场景可切割 |
| 3C 通路品牌 | 电商/3C | 抢早期采用者 |
| 传统换镜 | 无智能 | **最大基本盘**：把「该换镜的人」升级 |

**NIMO 在台定位建议**：  
「每天上班都戴得住的智能近视镜」——比 Rokid 更日常、更轻、更隐私、更接近普通眼镜价格带（视最终台币定价策略，建议显著低于全能 AI 镜，形成 **互补而非正面撞车**）。

### 4.3 台湾消费者决策链

```text
被种草（社群/门店TV） → 到店验光 → 试戴对比（舒适/外观/显示）
→ 关心隐私与同事眼光 → 询问度数能否做 → 看总价（主机+镜片）
→ 成交 → App 激活辅导 → 7 日回访调校 → 会员复购功能片/配件
```

操盘要点：**成交员是验光师/门市顾问，不是数码柜哥**。培训与激励必须围着他们转。

## 5. 台湾宝岛眼镜 KA 合作计划

### 5.1 合作愿景

与宝岛光学科技/宝岛眼镜集团建立 **「智能处方眼镜战略合作」**，目标 24 个月内把 NIMO 打造成宝岛体系内：

- **日常可戴智能镜的第一推荐**  
- **智能品类中客单价可复制、服务可标准、投诉可闭环的标杆 SKU**  
- 集团多品牌门店（宝岛 / 文雄 / 镜匠 / SOLOMAX / 米兰）可分层销售的共同单品

### 5.2 合作定位：互补型第二智能镜，而非替代 Rokid

明确向宝岛提案话术：

> Rokid 服务「全能 AI 尝鲜与旗舰体验」；NIMO 服务「隐私优先、全天处方、更接近普通眼镜价格的日常升级」。  
> 两者可共存于智能专区：按需求分流，提升智能品类总盘，而非零和替换。

这对已投入 Rokid 的宝岛最友好，降低决策阻力。

### 5.3 合作架构建议

#### 模式 A（首选）：台湾眼镜渠道阶段性独家 + 联合运营
- **独家范围**：台湾「传统眼镜连锁渠道」12–18 个月独家售卖 NIMO（不含品牌官网 DTC 与明确排除的 3C 点位）。  
- **宝岛义务**：体验网点、主推位、验光师认证人数、联合投放。  
- **NIMO 义务**：体验机、培训、售后备件、市场营销基金（MDF）、优先新品。

#### 模式 B：非独家深度联营
- 若独家谈不拢，则锁定 **门店数量、主推激励、会员专属价** 换深度曝光。

#### 商务主体
- 建议：NIMO/比特幻境 →（可设台湾子公司或授权总代）→ 宝岛集团采购/商品中心。  
- 镜片：优先接入宝岛既有加工与品牌镜片供应链（蔡司/依视路等门店能力），NIMO 提供智能主机适配参数。

### 5.4 分阶段落地路线图

#### 第 0 阶段｜立项对齐（月 0–1）
- 高层互访：商品、视光、营销、信息（EYESmart/App）四条线对齐。  
- 签署 MoU：独家意向、目标门店、试销范围、MAP 价格。  
- 完成 NCC/BSMI 等上市合规路径确认。

#### 第 1 阶段｜标杆店试销（月 1–3）
- 选择 **15–25 家** 高潜店：台北信义/东区、台中七期、高雄巨蛋商圈、百货柜点、Dream Plaza 类潮流点。  
- 每店：体验机 2、销售样机 2–4、完整试戴道具、桌面话术牌。  
- 派出驻店督导轮值，打磨 **15 分钟试戴 SOP**。  
- KPI：试戴率、试戴→成交、处方成功率、激活率、客诉。

#### 第 2 阶段｜百店复制（月 4–9）
- 扩展至 **80–120 家**（对标宝岛智能眼镜体验网点数），覆盖宝岛直营为主，优选文雄/镜匠等。  
- 上线宝岛 App / LINE@ / EYESmart 会员券：验光礼、功能片升级礼。  
- 联合开学季/换镜季大促（主机不破 MAP，镜片与会员点包装）。

#### 第 3 阶段｜全集团分层运营（月 10–18）
- 直营深度店：完整智能专区 + 认证验光师。  
- 策略联盟店：轻量陈列 + 预约转到旗舰店成交。  
- 评估是否进入大学企业团购、机场/百货联名快闪。

### 5.5 商品与定价策略（台湾）

**建议零售结构（示意，最终以成本与关税核定）**
- NIMO 主机处方包：锚定「可冲动升级的换镜总价」，建议明显低于 Rokid 活动价带，形成 **日常档**。  
- 镜片升级：防蓝光/变色作为门店主推毛利件。  
- 会员价：宝岛 App 专属加赠（充电配件/延保月）。  
- **MAP**：全渠道最低价管理；官网与宝岛价盘协同，杜绝电商砸价。

**套餐示例**
1. **通勤专注组**：主机 + 防蓝光片 + 激活教学  
2. **商务静音组**：主机 + 钛框联名 + 提词场景教程  
3. **学生学期组**（合规前提下）：导航/翻译场景 + 家长说明会（强调无摄像头）

### 5.6 门店运营 SOP（KA 核心交付）

**陈列**
- 智能专区内设「日常可戴」子墙：NIMO 与全能 AI 镜左右分流。  
- 禁止把 NIMO 放进普通镜框堆价区；需有试戴灯箱与隐私话术。

**人员**
- 每店至少 **2 名认证顾问**（验光 + 产品）。  
- 认证内容：屈光适配边界、瞳距与显示体验、App 绑定、竞品分流话术、隐私 FAQ。  
- 激励：主机销售奖金 + 功能片连带奖金 + 季度认证店奖励旅/旅游激励。

**服务闭环**
- T+0 交付或明确加工时效。  
- T+7 强制回访调校。  
- 固件问题：门店一键工单 → NIMO 客服 24–48h。  
- 坏机：备用机政策，避免顾客「没眼镜戴」。
