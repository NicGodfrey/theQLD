# Wave 3 — original theory only

This directory holds **original proofs**. Surveys, restatements of Lefschetz / BKM / Mason–Stothers / Polymath / Tunnell, and “named wall” expositions belong in `conjectures/*/REPORT.md` and are out of scope here.

Each note must contain: one new statement, a complete proof, and a one-line honesty tag. If the statement is later found in the literature, the tag degrades; the proof must still be self-contained.

The ten conjectures remain open. These notes do not claim otherwise.
